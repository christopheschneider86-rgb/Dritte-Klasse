## 🔒 Elternbereich

Passwortgeschützter Bereich für Eltern (Standardpasswort: `ZaboKids`).

| Funktion | Beschreibung |
|----------|-------------|
| 👶 **Kinder verwalten** | Profile hinzufügen, umbenennen (✏️), löschen |
| 🎛️ **Berechtigungen** | Fächer und Spiele pro Kind ein-/ausschalten |
| 📊 **Lernstatistiken** | Übersicht aller Kinder mit Fortschritt pro Fach |
| 📤 **Export / Import** | Alle Daten als JSON-Backup sichern und wiederherstellen |
| 🗑️ **Daten zurücksetzen** | Vollständiges Löschen aller Lernfortschritte |

> Wenn Spiele für ein Kind gesperrt sind, erscheint beim Klick auf den Spielen-Button ein Hinweis „Elternfreigabe erforderlich" – eine Navigation ins Spiel ist nicht möglich.

---

## 🪙 Münzen-System

Für jede richtige Antwort im Trainer gibt es **1 Münze**. Münzen werden pro Kind gespeichert und sind im Profil-Header jeder Fach-Seite sichtbar. Spiele können Münzen kosten (z.B. Deutsch-Vogel: –10 🪙 pro Runde).

## 💡 Tipps für Eltern

**📱 Als App speichern:** In Chrome (Android) oder Safari (iPhone/iPad) auf „Zum Startbildschirm hinzufügen" – die App verhält sich dann wie eine echte App.

**🔊 Ton an:** Lautstärke am Gerät aufdrehen, damit die Sprachausgabe im Deutsch-Trainer zu hören ist.

**💾 Backup:** Regelmäßig im Elternbereich exportieren – alle Daten liegen nur lokal im Browser (localStorage). Bei Cache-Löschung oder Gerätewechsel gehen sie sonst verloren.

**🐛 Bug melden:** Auf der Hauptseite gibt es den Button „🐛 Bug melden" – öffnet eine vorausgefüllte E-Mail mit Formular.

---

## 🛠️ Technisches

- **Technologie:** Reines HTML/CSS/JavaScript – keine Frameworks, keine externen Abhängigkeiten
- **Datenspeicherung:** Ausschließlich `localStorage` im Browser – keine Server, keine Cookies, kein Tracking
- **Offline-fähig:** Funktioniert nach dem ersten Laden auch ohne Internetverbindung
- **Kompatibel:** Chrome, Safari, Firefox – Desktop & Tablet optimiert
